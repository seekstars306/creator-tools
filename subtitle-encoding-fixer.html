Subtitle Encoding Fixer

Open a subtitle file that shows garbled characters. This page reads the file as bytes, tries several encodings, and shows you a preview of each one so you can pick the right decoding yourself. Nothing is uploaded.

Your file is read only in this browser tab. It is never sent to a server.

How to fix garbled subtitles

  1. Choose the garbled file, then preview the candidate decodings and compare their first lines.
  2. Pick the decoding that reads correctly, download the result as UTF-8, and keep the original file unchanged.

Common questions

Why do subtitles look garbled? The file was saved in an older regional encoding, but the player reads it as UTF-8. Decoding it with the original encoding restores the characters.

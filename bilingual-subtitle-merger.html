Bilingual Subtitle Merger

Merge two subtitle files for the same video into one file with both languages in each cue. Cues are matched by overlapping time, not by line number.

Both files are processed only in this browser tab. Nothing is uploaded.




Unmatched cues

How to merge bilingual subtitles

  1. Choose both subtitle files, and set an offset if the second file runs early or late.
  2. Merge, check the unmatched-cue report, then download the merged SRT or the two-style ASS file.

Common questions

Does this translate subtitles? No. It only merges two subtitle files you already have. It does not translate anything.
